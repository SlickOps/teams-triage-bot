# MAF: pinned to the version verified live against Foundry gpt-5-mini (structured
# output via ChatOptions.response_format, FoundryChatClient, the InterviewTurn
# round-trip).
#
# We depend on the SPECIFIC sub-packages we import rather than the convenience
# meta-package `agent-framework`. That meta-package resolves to
# agent-framework-core[all], whose "all" extra fans out to ~25 sibling packages
# with NO version pins. Any sibling publishing a release that requires a newer
# core (agent-framework-a2a did, needing core>=1.13) makes a pinned 1.10.0 build
# fail with ResolutionImpossible -- a build that breaks with zero repo changes.
# Naming the sub-packages keeps the pin reproducible and the image smaller.
#
# These three cover every agent_framework symbol brain/ imports:
#   core     -> Agent, ChatOptions, FunctionInvocationContext, MCPStreamableHTTPTool
#   foundry  -> agent_framework.foundry.FoundryChatClient
#   mcp      -> the MCP SDK that MCPStreamableHTTPTool needs at runtime (it is
#               only in core's "all" extra, so it must be requested explicitly).
# NOTE: leave pydantic as a range (>=2.11) above; a hard pin makes pip backtrack
# agent-framework and fail resolution.
agent-framework-core==1.10.0
agent-framework-foundry==1.10.0
mcp>=1.24.0,<2
